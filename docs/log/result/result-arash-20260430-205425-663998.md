## Method

Walked every `Wxx_*/` directory and recorded what's present. Canonical layout per `CLAUDE.md` is `tutorial/`, `exercise/`, `resources/` plus optional week-specific files. "Complete" here means all three are populated with non-trivial content; "non-canonical" means content exists but is placed at the week root or in differently-named subdirs.

## Gaps and recommendations

1. **Tutorial notebooks missing** for W03 (AR), W04 (PCA), W08 (NNMF), W09 (GPFA). Cheapest fix is to port the upstream library tutorials linked from the README (statsmodels ARIMA, sklearn PCA/NMF, elephant GPFA) into each week's `tutorial/` folder, mirroring the W01 EMD pattern.
2. **Layout standardization** — W06, W11, W12 have content but not in the canonical `tutorial/exercise/resources` shape. Move existing files into the right subfolders so the navigation rule in `CLAUDE.md` ("look inside that week's folder first") actually works. W11/W12 also use capitalized `Tutorials/` — rename to `tutorial/`.
3. **TBA weeks (W07, W10)** — the README already commits to CCA (W07) and SINDy (W10). Either lock those in by renaming the folders (`W07_CCA/`, `W10_SINDy/`) and seeding from the upstream docs, or formally mark them as student-led ("topic chosen by presenter").
4. **W09 GPFA** has only a `resources/tutorial.md` markdown — no executable notebook. Highest-effort gap; the elephant GPFA tutorial is the natural seed.
5. **No tests anywhere.** `pytest` is now in the pixi env but there are no test files. Low priority for a teaching repo, but worth a single smoke-test that imports each week's notebook deps.

## Suggested ordering

If working through the gaps, prioritize by student-impact:
1. **W03, W04** — these are early in the semester (week 3–4) and currently have exercises but no tutorial. Fix first.
2. **W06, W11, W12 layout** — quick wins, just file moves.
3. **W08 NNMF tutorial** — mid-semester, before the dim-reduction block ends.
4. **W09 GPFA** — biggest gap, but later in the semester (week 9), so more lead time.
5. **W07 / W10 TBA** — decide whether to lock in CCA/SINDy or leave open.
